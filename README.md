SQL, Python and Power BI analytics for a France–China cross-border e-commerce case study

# Cross-border Pharmacy E-commerce Analytics

## Contexte métier

Projet personnel inspiré d'une activité de commerce
électronique transfrontalier entre la France et la Chine.

Les données utilisées sont entièrement synthétiques.

## Objectifs

- Analyser les commandes et les ventes
- Suivre les stocks et les risques de rupture
- Étudier les délais logistiques
- Construire des indicateurs avec Power BI

## Technologies

- SQL Server / T-SQL
- Python / Pandas
- Power BI
- GitHub

## État du projet

En cours de développement — novembre 2026.
